## 📖 Overview
This repository contains the front-end source code for a responsive restaurant website tailored for **Taco Mazama** (UK). Built with a mobile-first approach, the project demonstrates foundational web development skills, UI/UX design principles, and the practical implementation of the Bootstrap CSS framework[span_2](start_span)[span_2](end_span).

## ✨ Key Features
* **Responsive Design:** Utilises Bootstrap's grid system (`bootstrap-grid.css` and `bootstrap.css`) to ensure a seamless browsing experience across mobile, tablet, and desktop devices[span_3](start_span)[span_3](end_span).
* **Customer Information Pages:** Includes dedicated front-end views for company history (`aboutus.html`) and crucial dietary/health information (`allegens.html`)[span_4](start_span)[span_4](end_span).
* **Asset Integration:** Incorporates web assets, including promotional hero images and third-party delivery/social links like Deliveroo and Facebook[span_5](start_span)[span_5](end_span).

## 🛠️ Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3, Bootstrap Framework[span_6](start_span)[span_6](end_span)
* **Version Control:** Git & GitHub
